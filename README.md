# Python CRUD Operations

A simple Python-based project demonstrating the four fundamental CRUD (Create, Read, Update, Delete) operations.

## Overview

This project demonstrates how to perform basic database operations using Python. It allows users to create new records, retrieve existing records, update information, and delete records from a database.

## CRUD Operations

| Operation | Description |
|---|---|
| Create | Insert new records into the database. |
| Read | Retrieve and display existing records. |
| Update | Modify existing records. |
| Delete | Remove records from the database. |

```bash

```

### 2. Navigate to the Project Directory

```bash
cd python-crud
```

### 3. Run the Application

```bash
python main.py
```

**Note:** SQLite3 is included in the Python standard library, so no additional installation is normally required.
